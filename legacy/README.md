# Legacy material (superseded)

This folder holds the first implementation (`xlshare/`, SimPy-based emulator), its benchmark
scripts, result files and the first manuscript version (`manuscript_v1/`).

It is kept only for the history of the project. **None of the numbers in the current manuscript
come from these files.** The emulator was replaced by the event-driven simulator in `camp_sim/`
(see the top-level README) after review feedback on its fidelity; several claims made in the old
README and result summaries (for example the cache-hit-rate and scalability figures) are not
supported by the current evaluation and should not be cited.
