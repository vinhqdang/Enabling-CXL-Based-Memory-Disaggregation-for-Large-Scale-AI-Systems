1. Research domain(s) and contributions

Research domains: performance modelling of computer systems; scheduling and memory management for large language model (LLM) inference; weight offloading to host-attached memory (page-locked DRAM, CXL memory expanders); max-plus algebra.

Contributions: (1) A max-plus model of layer streaming, in which a model's layers are partly resident in GPU memory and partly copied from host memory through a ring of k GPU buffers; we prove that the iteration time is the maximum mean of a family of tilings of the layer sequence, which also gives an evaluator for any placement. (2) Closed-form results for layers of equal cost: resident layers are useless when a layer computes at least as long as it copies; evenly spread resident layers attain the lower bound max(Lc, mf) whenever (k-1)f >= 2c; a contiguous block of resident layers, as produced by model-order filling in common tools, takes max(Lc, mf, rc+2c+(m-k)f), up to 2-c/f times the optimum. (3) A GPU runtime and 605 measured configurations on a Tesla T4 with real layer kernels of two model shapes: the model reproduces the measured iteration times with a mean error of 0.29%, even spreading is up to 1.50x faster than a contiguous block and needs two buffers where the block needs five. (4) Measurements at default clocks and an analysis of power-capping effects.

2. Novel aspects

This is a new manuscript; it does not extend previously published work. Novel aspects:
- To our knowledge, the first analysis of where resident layers should be placed when the remaining layers are streamed with prefetching. Existing tools fill GPU memory in model order (a contiguous block) or use fixed per-layer fractions without justification.
- An exact characterisation of the streaming pipeline as a max-plus linear system, with a tiling lemma that turns the cycle time into a combinatorial optimisation over segments of the layer sequence.
- Theorems with proofs: optimality of balanced (Christoffel-word) placements under the condition (k-1)f >= 2c, an exact formula for contiguous placement, a tight bound 2-c/f on its cost, and a bound for the two-buffer band c < f < 2c.
- Practical rules for runtimes: how many buffers to use and how to place resident layers, derived from per-layer compute and copy times.
- Validation on real hardware (Tesla T4, real layer kernels of Llama-3.2-3B and Llama-3.1-8B shapes, 605 configurations), including a slot sweep, an output-head case with non-uniform units, a repeatability check, and an honest account of how power capping and default clocks change the quantitative results.
- Open code, raw measurements and analysis scripts that regenerate every number and figure.

3. Match with the journal's scope

FGCS covers high performance computing, distributed dynamic resource management and scheduling, and, under Theory, scaling and performance theory and theoretical aspects of large-scale communication and computation. The manuscript addresses a resource-management and scheduling problem in the infrastructure that serves large AI models: how to place model layers across a fast but small GPU memory and a large host-attached memory tier (DRAM or CXL memory expanders), and how to schedule the transfers between them. It contributes performance theory (a max-plus model with proofs and closed forms for the iteration time) and validates it with measurements on real GPU hardware. The results give operators and runtime developers concrete rules for memory-disaggregated inference systems, which is an emerging infrastructure for the large-scale data centres and HPC systems that the journal addresses.
